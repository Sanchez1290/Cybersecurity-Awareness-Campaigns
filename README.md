# Cybersecurity Awareness Campaigns for Students

## Project Description
Our project is a cybersecurity awareness platform designed to teach students how to protect their personal information and recognize common cybersecurity threats.

## Topics
- Phishing
- Password Management
- Social Media Security
- Scam Identification
- Digital Citizenship
- Email Management
- Website Spoofing
- Tailgating and Piggybacking

## Planned Features
- Interactive cybersecurity scenarios
- Phishing awareness campaigns
- Cybersecurity learning modules
- Adaptive learning based on student understanding

## Intended Users
Schools and students, with the possibility of expanding the platform to organizations for basic cybersecurity training.
